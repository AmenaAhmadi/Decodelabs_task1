📖 Project Description

Brew Haven is a static coffee shop website developed using HTML and CSS. The project was created as part of a Frontend Development internship assignment to demonstrate the fundamentals of web design, including page structure, styling, navigation, images, and responsive layout principles.
The website presents a coffee shop with an attractive homepage, menu section, about section, contact information, and a clean user-friendly design.

🎯 Project Objective

The objective of this project is to create a visually appealing static webpage using HTML and CSS while applying proper web development practices such as semantic structure, styling, layout organization, and content presentation.
